## GB10 wordless generated artwork

The stage cover and Rush gallery are live FLUX.2 klein 4B renders for the fictional Northwind administrative planning-pilot proposal. The approved briefs depict recognizable proposal subjects: an administrative meeting suite for the briefing cover; a campus, private administrative workspace, workshop room and planning stationery for Rush. They contain no real people, patients, medical treatment, customer sites, logos or deployment claims. Model-authored prompts do not override these bounded scenario briefs. Each candidate stays private until the existing local Qwen3.6 vision lane reports both no lettering and a recognizable match to its assigned subject. The concise stage briefs fit completely within a 256-token conditioning window, verified with the pinned tokenizer including its chat template; this avoids unnecessary 512-token padding allocations while retaining the same model and memory reserves. All Nano images use overlapping 256-pixel VAE decode tiles at their original output dimensions to bound decoding activations. Free Mode chooses a 64–512-token conditioning window that fits the complete brief; overlong briefs are rejected rather than silently truncated. Original VAE settings are restored after each call. FP8 quantization had broken the checkpoint’s tied input/output embedding sharing; restoring the unused output projection to the original shared embedding removes the duplicate allocation without changing the hidden states used for image conditioning. Models, checkpoint files, quantization choices and memory reserve targets remain unchanged. A review rejection deletes the candidate and permits one regeneration before the image task fails closed. A memory failure permits one buffer-cleanup retry per whole image job; candidates stay quarantined throughout. The same review call checks both criteria and counts as real vision work. Blank paper and whiteboards are permitted; invented writing and data are not.

The accepted cover's unchanged PNG is embedded in slide 1 of the actual self-contained briefing HTML and its SVG preview. Rush creates a downloadable four-PNG proposal kit with a manifest, intended uses and pixel-file SHA-256 hashes. These illustrations support the proposal; they are never presented as evidence of a real installation. Runtime PNGs, decks and ZIPs remain private local outputs and are excluded from source distribution. Free Mode retains its user-directed prompts and existing lettering review. The deliberately written fictional whiteboard and chart remain supplied vision inputs. No extra model or external image service is introduced.
