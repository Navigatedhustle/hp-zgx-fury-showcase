# Actual implementation inventory

This distribution combines the requested source tree's current development/acceptance tools with the verified active deployment's application code. The live entry directory had forwarded to a different local deployment; that forwarding state, machine-specific plan and old Git history are excluded. Publication paths are relative to this distribution.

Retired/inactive: supplier and prospecting workflows/inbox are historical source/fixtures; the current API redirects their old pages and returns 410 for retired APIs. Historical Atlas vision/embedding/decision-engine model variants and alternate presentation model scripts are not launched or downloaded. Their retained source is not a claim of an active demo. Obsidian/customer documents, real integrations, outbound email/orders, live travel bookings/payments, private photography and video generation are not active features.

The historical large-deck generation/refinement code is included, but hardware acceptance covers the fast three-slide booth path and opening that actual project in the editor. It does not establish every advanced editor action or larger-deck latency. Remote physical-device audio/network quality remains separate from local browser/API verification.
