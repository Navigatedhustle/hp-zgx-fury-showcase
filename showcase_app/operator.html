What is measured?

GPU energy excludes CPU, cooling, networking, and other host consumption. Configure an actual wall-meter input on the host to measure the whole system. Missing measurements and long gaps remain unmeasured. Session idle power is included; measurements are not extrapolated across downtime.

Final endpoint counts are deduplicated by physical request ID. Reset excludes requests already in flight. Unavailable usage is shown separately. No cache discount is inferred from local caching; no batch, tool, tax, or regional premium is included. Hardware purchase, utilization, amortization, and administration are excluded, so no ROI or break-even claim is displayed.
