Presenter guide

Set up. Choose a task. Show the output.

1. Assign the screens.

Use Station setup on each browser. Put Economics and Why HP on passive displays, and the chooser on visitor laptops.

2. Choose a useful task.

Ask Atlas a scenario question, create three slides, build a fictional application, or generate an image.

3. Inspect the result.

Show grounding, previews, tests, and downloads. Generated results need review; Guided mode is clearly recorded.

Demonstrate shared AI.

Start one automatic short Factory build, then submit Atlas, a deck, and an image from independent sessions.

Explain the economics.

The event display counts live endpoint tokens. API costs are pricing scenarios. GPU electricity excludes the rest of the system and ownership costs.

Keep work safe.

All demos returns to the chooser while its workspaces stay loaded. Reconnect using the same browser. Cancel only your own job.

To reset the event window, use .venv/bin/python ops/event-session.py reset --name "Your event" in the host SSH shell. You can also use the reset form in Economics settings. No PIN or presenter code is required. Reset starts a new counter window and restores the default skin; jobs and artifacts are preserved.
