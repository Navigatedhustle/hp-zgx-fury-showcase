Measurement and scenario methodology

Inference runs on HP ZGX Fury. Local model output is not asserted equivalent to another model. Repricing uses the same measured token volume; tokenizers differ.

The aggregate event table extends the slide app's SQLite database. Gateway events count physical calls once. The original slide LlmCall table is retained for deck diagnostics and reconciliation, and is never added again to aggregate totals. Agent calls use run_id:call_id as stable keys, including failure/cancellation. No prompts are stored in aggregate events. Agent SQLite runs contain briefs and output excerpts; purge them before public operation if policy requires it.

API reported tokens only. Missing usage remains unknown. Cached input is separately reported and does not imply eligibility for another provider's billing discount. Default scenario treats all input as uncached. Rates and cache assumptions are editable, stored in the operator browser.

Recorded-work cost comparison

The chart below the experience table reprices completed text-model requests with known input tokens, output tokens, and valid elapsed time, across the retained physical-call ledger. Preparation calls are included. Unknown, failed, interrupted, pending, image, and audio usage is excluded. The chart always shows all text experiences together. Image Studio activity is listed separately because images have no comparable text-token billing. Cumulative bars and precise dollar counters update with each telemetry poll after usage arrives. Bars share a linear dollar axis that stays fixed between samples and expands with headroom when needed. Ratios divide each API estimate by estimated Fury electricity; they are not total-cost savings.

Standard API rates checked 16 October 2026, in USD per million tokens: GPT-6 Astra $10 input / $50 output (over 272K input tokens: $20 / $75 for the whole request); Claude Fable 5.1 $10 / $50; Claude Opus 5.5 $4 / $20; Gemini 4 Argon $2 / $10 through 30 November 2026, then $4 / $20 from 1 December 2026. These are selected frontier models with published pricing, not an exhaustive list or a quality ranking. No batch/cache discounts, cache writes, tools, taxes, or regional premiums are assumed. Local token counts are used without retokenization; another model may consume different tokens, including reasoning tokens.

API estimate = sum over eligible requests of (input tokens × applicable input rate + output tokens × applicable output rate) / 1,000,000. Published Gemini rates change on the documented date; other prices are a dated snapshot, not a live price feed. Source links and the date checked are available under the chart.

Fury electricity estimate = assumed whole-system kW × eligible request wall-time hours × electricity USD/kWh. The editable defaults, 1.5 kW and $0.25/kWh, are planning assumptions, not measured power or a verified tariff. Covered time is the union of eligible request intervals: overlapping requests count once and gaps are excluded. Request time includes admission/queue wait. The full assumed system draw is attributed to the selection; per-experience electricity estimates are not additive when experiences overlap. No historic wall-power integration is available. Hardware, idle time outside these intervals, facility cooling, hosting, network, and operations are excluded; the comparison is not a total-cost or realized-savings claim.

Monthly scenario

The separate monthly scenario multiplies the retained measured text-token mix by the selected monthly repetition count, using editable input, output, and assumed-cache rates. Its local all-in estimate includes hardware amortization, whole-system electricity for selected powered hours, hosting, network, and operations. Missing acquisition and operations inputs must be supplied to enable it. This monthly scenario is independent of the recorded-work chart.

GPU utilization/power are nvidia-smi samples, not total facility power. Request output tokens/s includes admission wait and is not server decode-only speed. Image queue waits for active Atlas language requests; GPU kernels already running cannot be preempted.
